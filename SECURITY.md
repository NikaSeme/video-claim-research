# Security and responsible disclosure

Do not open an issue containing a private video, transcript, credential, cookie, API key, personal profile, or unpublished research packet.

For a suspected vulnerability, send a minimal reproduction that uses synthetic data. Describe the affected version, expected boundary, observed behavior, and impact. Remove tokens, local paths, account identifiers, and private URLs before sharing logs.

This project does not authorize bypassing platform controls or accessing media without permission.
